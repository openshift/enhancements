# Architectural Decision Records

Cross-repo architectural decisions that affect the OpenShift platform.

## ADRs

- [adr-0001-cvo-orchestration.md](adr-0001-cvo-orchestration.md) - CVO as upgrade orchestrator
- [adr-template.md](adr-template.md) - Template for new ADRs

## How to Use

ADRs capture the **why** behind significant platform-wide decisions. Read relevant ADRs when:
- Understanding why a pattern exists
- Proposing changes that affect multiple components
- Writing enhancement proposals that touch platform architecture

## Creating New ADRs

1. Copy `adr-template.md`
2. Use next available number: `adr-NNNN-descriptive-name.md`
3. Fill in Context, Decision, Rationale, Consequences
4. Update this index
