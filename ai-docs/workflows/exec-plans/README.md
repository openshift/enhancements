# Execution Plans

Templates and guidance for planning multi-week feature implementations.

## When to Use

Use execution plans when:
- Feature spans more than 2 weeks of work
- Multiple teams or repositories involved
- Complex dependency chains between work items
- Tracking is needed beyond a single Jira epic

## Template

See [template.md](template.md) for the execution plan template.

## Structure

An execution plan should cover:

1. **Scope**: What's included and excluded
2. **Milestones**: Key deliverables with dates
3. **Dependencies**: Cross-team and cross-repo dependencies
4. **Risks**: Known risks and mitigations
5. **Status Tracking**: Weekly updates on progress
