# Execution Plans

**Category**: Workflow Template
**Last Updated**: 2026-10-23

---

## Overview

Execution plans are structured tracking templates for multi-week feature implementations. They help teams coordinate across components and track progress against enhancement milestones.

## When to Use

Use an execution plan when:
- Feature spans multiple components or repositories
- Implementation takes more than 2-3 sprints
- Multiple team members are contributing
- There are external dependencies or coordination points

## Template Structure

An execution plan typically includes:

| Section | Purpose |
|---------|---------|
| **Objective** | Link to approved enhancement, target release |
| **Milestones** | Date-based checkpoints with deliverables |
| **Dependencies** | External teams, APIs, CI infrastructure |
| **Risk Register** | Identified risks with mitigation plans |
| **Status** | Weekly progress updates |

## Relationship to Enhancements

Execution plans complement enhancement proposals:
- **Enhancement**: Documents the design (what and why)
- **Execution plan**: Tracks the implementation (how and when)

The enhancement proposal is the authoritative design document. The execution plan is a living tracking document that may be stored in the team's project management tool or as a separate document.
